Synchronisation

Retrouve les mêmes données sur ton Mac et sur ton téléphone, via une sauvegarde privée sur ton compte GitHub.

Non connecté sur cet appareil

À faire une fois par appareil. Les données se renvoient ensuite automatiquement à chaque modification.

Comment créer ce token ?
  1. Va sur github.com/settings/tokens
  2. Generate new token → Generate new token (classic)
  3. Donne-lui un nom, coche uniquement la case gist
  4. Generate token, puis copie-le (il ne s'affichera qu'une fois)
  5. Colle-le ci-dessus, laisse « ID de synchro » vide, clique « Connecter cet appareil »

—

Sur ton autre appareil

Ouvre l'appli, va dans Synchronisation, colle le même token (ou un nouveau token « gist » de ton compte) et l'ID de synchro affiché ci-dessus, puis clique « Connecter cet appareil ». Ses données actuelles seront remplacées par celles de la synchro.
